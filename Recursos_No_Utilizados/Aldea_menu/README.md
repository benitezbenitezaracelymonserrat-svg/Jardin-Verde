# Recursos no utilizados del menú

Esta carpeta documenta los recursos del prototipo `Aldea_menu` que no forman
parte de la escena integrada ni de sus dependencias de ejecución.

## Recursos descartados

- `Assets/Animacion/Text (TMP).controller`
- `Assets/Animacion/TituloEntrada.anim`
- `Assets/imagenes/SliderKnobWood.png`
- `Assets/imagenes/SliderRailWood.png`
- `Assets/imagenes/volver.png`
- `Assets/Scenes/SampleScene.unity` (escena vacía del prototipo)
- `Assets/_Recovery/0.unity`
- `Backups/`, `work/`, `Logs/`, `Library/` y `UserSettings/` (copias o datos generados)

Los originales siguen dentro de `Aldea_menu` como respaldo del prototipo. El
proyecto principal sólo registra como escenas ejecutables
`MenuPrincipal.unity` y `SampleScene.unity`; ninguno de los elementos de esta
lista está referenciado por esas escenas.
