# Jardín Verde

Proyecto Unity 6000.3.7f1.

El juego inicia en `Assets/MenuPrincipal/Scenes/MenuPrincipal.unity` y el botón
**Jugar** carga `Assets/Scenes/SampleScene.unity` después de la transición.

Las imágenes y el audio originales del menú se consumen como paquetes locales
desde `Aldea_menu/Assets/imagenes` y `Aldea_menu/Assets/Audio`. Esto conserva sus
GUID y evita duplicar recursos dentro del repositorio.
